遊戲操作說明與訓練指南

🎯 遊戲目標

透過訓練好的 Teachable Machine AI 模型，展現特定的**手勢/圖像/聲音/姿勢**，觸發相對應的魔法元素（如：火焰、海浪、森林），獲得分數並完成挑戰！

🚀 如何訓練並導入您的模型 (3 步驟)：

  1. 造訪 Google Teachable Machine。
  2. 選擇 Image Project、Pose Project 或 Audio Project，訓練至少 2 個類別（建議類別名稱可包含：Fire, Water, Leaf 或自訂名稱）。
  3. 點擊 Export Model ➔ 點擊 Upload (shareable link) ➔ 複製生成的模型 URL 貼入本頁面的輸入框中並點擊「載入模型」。

✨ 辨識連動效果說明：

  • 換背景 & 主題色彩：系統會依據最高信心度的分類切換背景與畫面風格。
  • 音效與視覺粒子：辨識成功觸發 Web Audio 音效與 Canvas 魔法粒子爆炸。
